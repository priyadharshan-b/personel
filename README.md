# Priyadharshan Portfolio & Auth Portal

An ultra-modern, high-fidelity landing and authentication page crafted specifically for Priyadharshan.

## ✨ Features

- **Exact Visual Match**: Replicates the deep mulberry/plum gradient, typography hierarchy ("Hey, I'm", "PRIYADHARSHAN", subtitle), and pill auth buttons.
- **Glassmorphic UI**: `backdrop-filter: blur(16px)` with delicate light-refracting borders and subtle ambient mesh lighting.
- **Interactive Auth Experiences**:
  - **Google Sign-In**: Interactive Google OAuth modal simulation with avatar selection, loading spinner, and success toast.
  - **Email Auth Drawer**: Sleek slide-up sheet with live email/password validation and eye-toggle.
  - **Sign In / Sign Up Switcher**: Instantly toggles context between new registration and returning user login.
- **Palette Switcher**: Easily test different colorways (Mulberry Plum Original, Cyber Violet, Sunset Rose, Emerald Noir, Midnight Sapphire).
- **Responsive Viewport**: Switch between realistic **Mobile Device Mockup** (with status bar & dynamic island) and **Full Responsive View**.

## 🚀 How to Run

1. Simply double-click `index.html` to open it in any web browser (Chrome, Edge, Safari, Firefox).
2. Or serve it using any local static server:
   ```bash
   npx serve .
   # or
   python -m http.server 3000
   ```
